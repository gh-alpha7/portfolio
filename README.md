# portfolio

Personal site for Subham Singh: https://gh-alpha7.github.io/portfolio/

A static page with no build step: `index.html`, `styles.css`, `main.js`.
The hero includes a small breakout game. Breaking a glowing brick unlocks
that resume section. It supports keyboard (← → / A D, Space) and touch/drag.

## Local preview

Serve the folder with any static server, e.g. `npx serve .`, and open it in a browser.

## Deploy

GitHub Pages serves the `gh-pages` branch. Copy these files to that branch and push.
